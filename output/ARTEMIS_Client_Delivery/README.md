# ARTEMIS Client Delivery Versions

এই folder-এ তিনটি original project version রাখা হয়েছে। সব folder এবং file name English করা হয়েছে, কিন্তু document-এর client-facing content German রয়েছে।

## Version 1 Initial

প্রথম proposal package। Initial quotation, comparison, editable proposal এবং internal notes আছে।

## Version 2 Refined

Reference design অনুসরণ করে উন্নত করা proposal package। Version 1-এর তুলনায় অতিরিক্ত editable comparison এবং artifact verification আছে।

## Version 3 Final

সর্বশেষ verified delivery। Updated proposal, management comparison, email templates, editable sources এবং final QA support documents আছে। Client submission-এর জন্য এই version ব্যবহার করুন।

## Common folder names

- `01_CLIENT_READY` — Client-কে পাঠানোর files
- `02_EDITABLE_SOURCE` — Editable source files
- `03_INTERNAL_SUPPORT` — আপনার preparation ও verification files
