# ARTEMIS client package ব্যবহার করার নিয়ম

এই package WebDev Software Solutions-এর নামে তৈরি। Client project পাওয়ার নিশ্চয়তা দেওয়া যায় না; এখানে factual comparison, পরিষ্কার scope, proposed price এবং next step তৈরি আছে। কোনো email পাঠানো বা website publish করা হয়নি।

## ফাইলগুলো কীভাবে ব্যবহার করবেন

1. `01_CLIENT_READY/02_Management_Comparison_German.pdf` হলো প্রথম পরিচয়ের জন্য এক পাতার comparison। প্রথম email-এর সঙ্গে এটিই দিন।
2. `01_CLIENT_READY/03_Client_Email_Templates_German.txt`-এ প্রথম email ও meeting-এর পর quotation পাঠানোর email আছে। দ্বিতীয়টি meeting হওয়ার পর ব্যবহার করুন।
3. Client আগ্রহ দেখালে `01_CLIENT_READY/01_Project_Proposal_German.pdf` দিন। এতে scope, price, payment, schedule এবং acceptance criteria আছে।
4. `02_EDITABLE_SOURCE/01_Project_Proposal_Editable_German.docx` Word-এ edit করতে পারবেন। `Quotation_Data.json`-এ price ও business details একসঙ্গে রাখা আছে। JSON edit করলে PDF/DOCX নিজে থেকে বদলাবে না; দুটোতেই একই পরিবর্তন করুন।
5. `03_INTERNAL_SUPPORT` folder আপনার জন্য; client-কে পুরো folder forward করবেন না। Follow-up, demo script এবং evidence notes এখানে আছে।

## Meeting-এ সবচেয়ে কার্যকর উপস্থাপনা

Marketing বা digital/standort decision-maker-এর সঙ্গে 12 মিনিটের presentation ঠিক করুন। প্রথমে জিজ্ঞেস করুন তাঁদের priority কী: patient information, appointment path, content maintenance নাকি mobile use।

একই তিনটি কাজ existing site এবং local concept-এ দেখান: সঠিক Standort খোঁজা, সময়/সেবা বোঝা, appointment link বা ফোন পাওয়া। শুধু সুন্দর design বলার বদলে প্রতিটি পরিবর্তন রোগীকে কী কাজ করতে সাহায্য করে তা ব্যাখ্যা করুন।

Existing national ARTEMIS site-কে খারাপ বলবেন না। সেটি অনেক বড় network সামলায়; আপনার এই quotation দুইটি location-এর scoped pilot। পুরোনো local AI prototype-এর fake reviews বা fake submit bug-কে official live site-এর bug হিসেবে বলবেন না।

Demo-এর আগে local site চালিয়ে desktop ও mobile width, menu, search, booking dialog, links এবং browser back যাচাই করুন। বর্তমান concept-এর production URL, পূর্ণ visual QA ও deployment এখনো বাকি; quotation-এ এই কাজগুলো অন্তর্ভুক্ত। কোনো untested screenshot বা fabricated Lighthouse score দেখাবেন না।
